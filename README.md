# projetophp

Tema: Um Site de uma hamburgueria.

Descrição: Um Site de uma hamburgueria. O site irá conter opções de sabores de hamburgueres artersanal, refrigerantese e combos. 
O objetivo do site é fazer o cliente enviar um pedido para o restaurante.
Os pedidos serão salvos em um arquivo json.
