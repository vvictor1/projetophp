# projetophp

Tema: Um Site de uma hamburgueria.

Descrição: Um Site de uma hamburgueria. O site irá conter opções de sabores de hamburgueres artersanal, refrigerantes e combos. 
O objetivo do site é fazer o cliente enviar um pedido para o restaurante.
Os pedidos serão salvos em um arquivo json.
O cliente irá selecionar o seu pedido e, logo após, terá que se cadastrar colocando seu nome, número e endereço. Depois o cliente irá selecionar a forma de pagamento.
O site terá uma opção de suporte ao cliente, onde o cliente colocará seu nome, seu email e sua reclamação, que será salvo em um arquivo json. 
Depois, aparecerá o tempo estimado para a entrega.

- Os refrigerantes só estarão disponíveis nos combos; Não serão vendidos separadamente.
- O site terá inicialmente o menu onde aparecerá o titulo do site.
- Logo a baixo, aparecerá o cordápio, onde terá as opções de hámburgueres e combos.
- E, abaixo do cárdapio terá a opção de suporte ao cliente.
- Logo após a seleção dos pedidos, o cliente será direcionado a página de seleção de pagamento.
- Depois, o site exibirá uma mensagem de agradecimento ao cliente e o tempo estimado para a entrega.
